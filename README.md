# Traffic Accident Hotspot Classifier
by Pierina Melo and Vivianna Grande.

## Overview
This project analyzes Philadelphia traffic crash data to identify risky
locations, times of day, and weather conditions. We cluster crash
locations into hotspots and look at which conditions are associated
with higher-risk crashes.

## Data
- Source: PennDOT crash data, Philadelphia 2025 subset 
  (https://experience.arcgis.com/experience/51809b06e7b140208a4ed6fbad964990/page/County)
- File used: (data/raw/CRASH_PHILADELPHIA_2025.csv)

## Project Structure
- `data/raw/` - original crash data (unmodified)
- `src/` - Python scripts
- `README.md` - project description
